# OWASP Top 10 for LLM Applications (2025): threats, controls, evidence

Scope: the note interpreter (`application/interpreter.py`), the bounded
orchestrator (`application/orchestrator.py`, ADR-0016, ADR-0018), the
template drafter and the OpenAI router. The model never acts: rules
decide *whether* to act, the model chooses *how* inside an envelope
computed by code, a deterministic guard approves, and the outbox is the
only executor.

Every test cited below carries `@pytest.mark.owasp_llm("LLMxx")`;
`tests/meta/test_owasp_llm_traceability.py` fails if a row cites a test
that does not exist or does not carry the risk, or if a risk marked
*Mitigated* has no evidence.

| Risk | Threat here | Controls | Evidence | Status |
|------|-------------|----------|----------|--------|
| LLM01 Prompt Injection | A note, title or project name tells the model to mark tasks done, email someone or escalate; a model's earlier answer smuggles instructions into the next step | Every tracker text field is screened after NFKC normalisation; a flagged task withholds the note and the model never sees titles or project names; notes sit in an escaped, delimited block named as data; the transcript returns only closed violation codes, never model text; the history tool returns code-owned fields only; decisions come from dates and status, so an injection cannot change *whether* to act | `tests/scenarios/test_llm_safety.py::test_s8_prompt_injection_note_is_untrusted_data`, `tests/unit/domain/test_screen_and_prefilter.py::test_injection_patterns_are_flagged`, `tests/unit/processing/test_orchestrator.py::test_suspicious_note_is_withheld_from_the_model`, `tests/unit/processing/test_orchestrator.py::test_instruction_in_the_title_withholds_the_note`, `tests/unit/processing/test_llm_hardening.py::test_tracker_instruction_surfaces_are_withheld`, `tests/unit/llm/test_owasp_llm_top10.py::test_model_text_is_never_fed_back_into_the_next_prompt`, `tests/unit/llm/test_owasp_llm_top10.py::test_history_tool_returns_closed_facts_never_message_text` | Mitigated |
| LLM02 Sensitive Information Disclosure | Names, e-mail addresses or phone numbers reach the provider; the model writes note text into stored records; logs leak notes | The model sees recipient *kinds*, never names, titles or project names; contacts in notes are redacted before exposure; `store=False`; the model's rationale is rejected if it contains contacts, links or a six-word run of the note, so raw notes are never stored; logs are allow-listed and carry digests, not text | `tests/unit/processing/test_llm_hardening.py::test_model_context_omits_display_fields_and_redacts_contacts`, `tests/unit/llm/test_owasp_llm_top10.py::test_a_rationale_cannot_copy_the_note_into_storage`, `tests/unit/llm/test_owasp_llm_top10.py::test_planning_request_holds_no_secret_or_display_data`, `tests/unit/llm/test_openai_backend.py::test_request_is_strict_private_and_single_shot`, `tests/unit/cli/test_logging.py::test_logging_emits_one_json_line_without_note_or_exception` | Mitigated (a note can still name a person; provider retention terms need deployment review) |
| LLM03 Supply Chain | A compromised SDK or an unexpected model | `uv.lock` with hashes, `pip-audit` and image scans fail the build, scanners pinned by digest; routes may only name catalogued models with configured prices | `tests/meta/test_security_gates.py::test_dependency_and_image_scans_fail_the_build`, `tests/unit/llm/test_config.py::test_unknown_model_is_rejected` | Mitigated (provider-side model integrity is the provider's) |
| LLM04 Data and Model Poisoning | A poisoned cache entry or evaluation set changes behaviour | No training or fine-tuning; cached interpretations are revalidated and re-grounded against the current note on every hit; evaluation bundles are bound to dataset, recording and pipeline digests | `tests/unit/llm/test_language_workflow.py::test_cache_metadata_and_grounding_are_revalidated`, `tests/eval/test_harness.py::test_archived_artifacts_and_source_labels_are_preserved` | Mitigated |
| LLM05 Improper Output Handling | Model output becomes message text, markup, a format string or an oversized payload | The plan schema has no text fields; strict JSON with duplicate-key and depth checks; code composes every message from reviewed fragments and renders facts in one regex pass, never `str.format`; fragments are held to the same fact rules; delivery bounds are enforced on every path; any invalid output falls back to the baseline template | `tests/property/test_agent_containment.py::test_any_model_output_yields_an_allowed_action`, `tests/unit/domain/test_guard.py::test_every_composable_message_passes_the_fact_rules`, `tests/unit/processing/test_llm_hardening.py::test_model_prose_cannot_reach_the_message`, `tests/unit/processing/test_orchestrator.py::test_any_model_failure_falls_back_to_the_baseline`, `tests/unit/processing/test_orchestrator.py::test_duplicate_keys_cannot_smuggle_a_foreign_recipient`, `tests/scenarios/test_llm_safety.py::test_s7_malformed_llm_json_falls_back_safely`, `tests/unit/domain/test_messages.py::test_render_is_one_pass_and_never_formats`, `tests/unit/llm/test_openai_backend.py::test_request_is_strict_private_and_single_shot` | Mitigated |
| LLM06 Excessive Agency | The model sends, silences, re-routes or releases work on its own | Three read-only tools; choices limited to an envelope with opaque recipient references and no `no_action`; priority only rises; escalation only after an unanswered message; the only new power that affects delivery is *hold for review*, which can only reduce automation; a held action is never claimed by a dispatcher and only an operator command releases it | `tests/unit/llm/test_owasp_llm_top10.py::test_the_model_has_exactly_three_read_only_tools`, `tests/unit/domain/test_guard.py::test_every_escape_attempt_is_a_closed_violation`, `tests/property/test_agent_containment.py::test_any_model_output_yields_an_allowed_action`, `tests/unit/processing/test_orchestrator.py::test_duplicate_keys_cannot_smuggle_a_foreign_recipient`, `tests/unit/processing/test_review_flow.py::test_held_action_waits_until_a_person_approves_it`, `tests/contract/persistence/test_review_hold.py::test_held_action_is_never_claimed` | Mitigated (notes written to make the model hold everything delay mail; the held-backlog alert and the `templates` planner switch cover it) |
| LLM07 System Prompt Leakage | The prompt reveals secrets or is treated as a security boundary | Prompts and requests carry no keys, URLs or personal data; every rule in the prompt is enforced again by the guard, so leaking the prompt grants nothing | `tests/unit/llm/test_owasp_llm_top10.py::test_prompts_carry_no_secrets_or_personal_data`, `tests/unit/llm/test_owasp_llm_top10.py::test_planning_request_holds_no_secret_or_display_data` | Mitigated |
| LLM08 Vector and Embedding Weaknesses | — | The service has no retrieval store, embeddings or vector database | — | N/A |
| LLM09 Misinformation | A message invents dates, names or status, claims an earlier contact that never happened, or pressures a recipient without cause | The model cannot write text; facts are rendered from tracker data; "we wrote before" is allowed only when a sent action exists; a firm tone only after an unanswered, overdue message or for an escalation; evidence must be quoted verbatim from the visible note; interpretations must be grounded | `tests/unit/domain/test_guard.py::test_firm_tone_and_earlier_contact_need_verified_history`, `tests/unit/llm/test_owasp_llm_top10.py::test_mentioning_an_earlier_message_requires_one_that_was_sent`, `tests/unit/domain/test_guard.py::test_every_composable_message_passes_the_fact_rules`, `tests/unit/llm/test_language_workflow.py::test_cache_metadata_and_grounding_are_revalidated` | Mitigated (tracker data itself can be wrong) |
| LLM10 Unbounded Consumption | A looping model, a slow provider or many workers burn tokens and money | At most four steps; a per-call timeout and one total plan deadline; a semaphore; token caps per route; a circuit breaker per model; the worst-case cost is reserved before each call in the process budget **and** in a PostgreSQL ledger shared by every worker, failing closed when the ledger is unreachable; unknown bills are charged at the bound and overruns close admission; a rerun of an unchanged task never calls the model | `tests/unit/processing/test_orchestrator.py::test_step_budget_bounds_a_model_that_never_complies`, `tests/unit/processing/test_plan_deadline.py::test_steps_share_one_total_deadline`, `tests/unit/llm/test_router.py::test_concurrent_calls_reserve_budget_before_network`, `tests/unit/llm/test_router.py::test_workers_share_one_daily_budget`, `tests/integration/persistence/test_spend_ledger.py::test_concurrent_workers_cannot_overshoot_the_limit` | Mitigated (a provider-side spend cap remains the external hard limit) |

## Not claimed

* General prompt-injection immunity: screening is a signal; the controls
  above hold even when it misses.
* Measured quality of a live provider: the replay evaluation is
  synthetic; provider quality remains UNVERIFIED.
* Full ASVS L2 compliance (see `15`).
